# Tinkercad traffic light-
This is very first project of mine "traffic light"
# How it works 
**Green Light ** The Green LED turns ON for 5 seconds . 
**Yellow Light:** The Green LED turns OFF, and the Yellow LED turns ON for 2 seconds . 
**Red Light:** The Yellow LED turns OFF, and the Red LED turns ON for 5 seconds.
# Components used 
1x Arduino Uno R3
3x LEDs (1 Red, 1 Yellow, 1 Green)
2x 220Ω Resistors
1x 240Ω Resistors
1x Breadboard
Jumper wires
